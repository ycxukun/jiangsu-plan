# 专业组研究脚本（不参与网站部署）

数据不在仓库里：2025、2026 招生计划专刊和中间结果打包在对话附件 zyz-research-20261117.tar.gz。

- base.py → base.pkl：26 专刊每个专业组的基础表
- inst.py：25/26 两年按「专业 + 班型 + 校区」对照，得出每个 26 组的前身（延续/拆出/合并/新增）
- stats6.py：25 组线按位次折算到 26，算相对涨跌（扣全省 −6）
- js29.py：江苏 29 所保研高校体检
- school_act.py：各校重组程度与回报
- pref.py：各分段偏好变化（属性拆解）
- profile.py：单校专业组画像
- price.py / price_reg.py / price_loso.py：第一轮，同校内各属性的价格（学校固定效应），24/25/26 三年 + 稳健性
- school_price.py：第二轮，学校属性在各档次的涨跌（24→25、25→26）
- compete.py / compete_loc.py：第三轮，附近供给变化 → 谁和谁抢同一批人
- supply.py：补充，各档次×各类组的计划数变化
- card.py：专业组变化体检卡（A 结构、B 本组计划、C 同档同类计划、D 班型、E 选科、F 校区、G 学校事件、H 去年走势）
- main_contra.py：全省体检卡 → 结构/计划 vs 类型的解释力，分数段×层次×地区
