# 江苏专科招生计划变化知识库 V0.2

基于上传的 `312 数据库高职专科(1).xlsx` 生成。

## 口径
- 每一行专业数据作为事实源。
- 身份键：院校专业组代码 + 专业代码。
- 院校和专业组按 25 年专业最低分 × 计划数计算加权均分排序。
- 保留本科版骨架：筛选、志愿表、导出、特殊类型、体检受限、批注、回顶悬浮球。

## 主要输出
- `specialty_import_audit.csv`：导入统计。
- `specialty_risk_audit.csv`：专科首轮谨慎/刺客专业提示。


## 专业目录重匹配
使用《高职专科专业目录_单表合并版》作为高职专业目录事实源，重新匹配专业名称、专业类、专业大类。总专业 7660 条，匹配 7660 条，未匹配 0 条。


## 地区筛选更新
- 省份支持多选。
- 选择江苏后，可继续在“江苏十三太保”中选择南京、苏州、无锡、常州等地级市。
- 勾选城市会自动限定江苏；适合家长只看南京/苏州等地区的场景。
